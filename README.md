Daily Rituals is a beautifully designed, single-file daily habit tracker built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies, no internet required after download.
Features
10 daily habits organized by time of day — Morning, Any Time, Afternoon, and Evening
Unified hero card showing your streak, circular progress ring, completion stats, and a 10-segment progress bar in one glance
Auto-resets every day — progress is saved locally and wiped automatically at midnight, so you always wake up to a clean slate
Streak tracking — builds your consecutive day count and visualizes your last 7 days
Ripple tap feedback, icon animations, shimmer effects, and spring-eased checkmarks for a satisfying experience
Undo support — instantly reverse your last check-in
Completion celebration — confetti explosion and a trophy overlay when all 10 are done, with your streak and time-to-complete
Done timestamps — each completed task shows the time you finished it
Daily motivational quote that rotates each day
Toast notifications with encouraging messages as you progress
Tech
Single .html file — Cormorant Garamond + JetBrains Mono via Google Fonts, ambient SVG blob backgrounds, CSS grain overlay, and localStorage for persistence. Zero build step. Open in any browser and go.
